# Box Health Agent

One Python process that samples a machine every 5s (CPU/RAM/disk/network/processes), probes the network every 15s (DNS, TCP connect, packet loss, API endpoint), evaluates 7 fixed alert rules, and serves it all over FastAPI + a static dashboard.

- **Run it**: `make build && make up`. Uses a named Docker volume, not a bind mount — SQLite's locking is unreliable over Docker Desktop's Windows bind-mount bridge.
- **Code layout**: `app/service/collector.py` (5s sampler), `app/service/probes.py` (15s network probes, each hard-timeout-wrapped so a hung DNS lookup can't stall the loop), `app/db/` (SQLite schema + storage helpers), `app/utils/rules.py` (`RuleEngine`, one boolean condition per rule per tick → open/close alert), `app/apis/` (routes + dashboard), `main.py` (wires all loops + the API server into one asyncio process).
- **API**: `GET /health`, `/metrics?name=&since=`, `/alerts?open=`, `/processes?sort=`, `/` (dashboard).
- **Config**: `config.toml` for the watch-list/probe targets/server/retention settings; all rule thresholds are also env-var overridable (e.g. `RAM_HIGH_THRESHOLD`) for safe demoing without editing code.
- **Demo commands** (`demo/` holds the leak/zombie scripts the Makefile copies in): `make demo-cpu` triggers `cpu_high` (opens ~60-70s into sustained >85% CPU); `make demo-ram` triggers `ram_high` (recreates the container with `--memory 1g -e RAM_HIGH_THRESHOLD=35` so it's safe to allocate); `make demo-memory-climbing` triggers `memory_climbing` (recreates the container with smaller history buckets so it fires in ~1min instead of ~11min — run `make up` afterward to restore the real one-minute buckets); `make demo-disk` / `demo-disk-clear` trigger/clear `disk_high` on the tmpfs mount; `make demo-kill` triggers `process_died` via a real `kill -9`; `make demo-zombie` triggers `zombie` (opens at 30s, closes at 40s); `make demo-network-down` / `-check` / `-up` trigger/verify/clear `network_lost` (use `-check` instead of curl while disconnected — the host port mapping dies too).
